首次授权与常见问题

macOS 辅助功能：系统设置 → 隐私与安全性 → 辅助功能，允许启动外设服务的终端或宿主应用，例如 Terminal、iTerm 或 Codex。重新启动服务后再绑定。

Claude Code：先在电脑安装并登录，可运行 claude auth login。在下方控制台填写项目绝对路径，创建会话。

手机打不开：手机使用 HTTPS 连接入口，不能使用电脑的 127.0.0.1 地址。先确认电脑服务仍在运行。

麦克风：在手机浏览器的站点权限中允许麦克风。添加到主屏幕后也需在对应入口授权。

安装检查：运行 npm run controller -- --check；检查通过后仍需实际绑定与录音验证。
