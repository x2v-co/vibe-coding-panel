# Micro Keycap Symbols

The command icons use Lucide's vector components: Zap, CircleCheck, CircleX,
Split (rotated 90 degrees), and Mic. Lucide is already an app dependency and
ships its ISC/MIT notices. Source: https://github.com/lucide-icons/lucide

`codex.svg` is the unmodified Codex brand mark from LobeHub Icons (MIT):
https://github.com/lobehub/lobe-icons/blob/63c800e3db6427b3f156f7b88d426ccb3f7277a1/packages/static-svg/icons/codex.svg

See `LICENSE.lobehub` for its copyright and permission notice. These are standard
vector icons, not an official Micro keycap asset pack. Brand usage does not imply
affiliation with OpenAI or Work Louder or grant rights to their trademarks.

The panel, layout preview, and icon picker share these assets. Button actions
are configured separately. Recording state changes the key lighting, not the
printed microphone symbol.
