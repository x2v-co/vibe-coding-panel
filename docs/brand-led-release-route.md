# 品牌推广型发布路线

更新时间：2026-09-04

## 定位

Vibe Panel 是一个面向 AI 编程 Agent 的实体感控制面板。用户可以在手机或桌面端通过语音、按键、Workspace 和状态屏幕控制电脑上的 Agent。

首个产品主张：

> 用手机控制电脑上的 AI 编程 Agent。

它暂时不应该被包装成新的 IDE。真正有传播价值的是实体键位布局、大语音键和可定制 Agent 工作流，因此它可以成为 AI、云服务、开发者工具、硬件和编程教育品牌的互动展示载体。

## 发布阶段

### 1. 免费公开 Beta

- GitHub 发布客户端和本地 Bridge。
- 以 HTTPS PWA 的形式提供手机安装。
- Agent 继续在用户自己的电脑上执行。
- 提供无需登录的模拟演示模式。
- 用二维码或一次性配对码连接手机与桌面 Bridge。
- Tailscale 只作为测试路径，不作为大众首次使用方式。
- 公开发布前增加 HTTPS、过期配对码、设备撤销和数据说明。

### 2. 合作示范主题

先制作 2～3 个示范版本：

- AI 模型：提示、审查、重构、解释。
- 云服务：部署、日志、预览、回滚。
- 开发者工具：Issue、分支、测试、Pull Request。
- 硬件品牌：品牌化外壳、键位和桌搭主题。
- 教育品牌：引导式课程和编程挑战。

合作主题必须改变实体键位或默认工作流，而不只是换颜色。

### 3. 品牌赞助活动

标准合作包可以包括：

- 一个联合品牌主题或布局。
- 一组品牌专属 Agent 工作流。
- 一条短演示视频和一篇教程。
- 一次编程挑战或社区活动。
- 一份匿名汇总报告：激活、配对、周活跃、主题使用、工作流执行、点击和分享。

第一家合作方可以用现金、API 额度、云资源、奖品或渠道支持参与。等有真实使用数据后，再把合作标准化成现金赞助套餐。

## 产品边界

- 合作主题明确标注为赞助或官方合作内容。
- 品牌可以自定义键名、图标、默认指令和布局结构。
- 主题页可以链接教程、优惠或活动。
- 控制面板不放横幅广告和打断式弹窗。
- 不强迫用户更换 Agent、模型或云服务商。
- 不出售用户的任务内容、录音、提示词或源代码。
- 统计尽量采用匿名汇总，并在需要时征得同意。
- 没有授权时，不使用容易让人误解为 Codex 官方背书的表达。
- 手机不支持屏幕捕获时改为上传截图，不承诺跨 App 截屏。

## 渠道与指标

渠道包括 GitHub、PWA、Product Hunt、Show HN，以及 B 站、小红书、抖音、知乎、X 和 Reddit AI 编程社区。

内容重点展示动作：手机按键、电脑 Agent 开始工作、状态更新、任务结果。不要只介绍功能。

发布前持续统计：配对完成率、首次任务耗时、周活跃、任务次数、语音成功率、主题使用、合作工作流执行、分享率和 GitHub 反馈。

首个验证门槛：10 个真实安装、5 个每周使用者，以及至少 3 人主动要求某个品牌工作流或持续回来使用。没有行为数据之前，不要把截图或候补名单当作品牌价值。

## 推荐顺序

1. 先解决语音可靠性和错误诊断。
2. 手机隐藏不可用的 Capture，改用上传截图。
3. 增加无需登录的演示模式和二维码配对。
4. 发布开源 Beta、README 和 30 秒演示。
5. 用两个非赞助示范主题证明合作格式。
6. 用额度或联合传播做一次小规模品牌试点。
7. 根据真实数据形成可重复的赞助合作方案。

## 下一决策

先选择一个合作品类进行验证：AI 模型、云服务、开发者工具、硬件或编程教育。只找一个具体合作方，不要先做泛化的品牌市场。
